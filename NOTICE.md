# Notices and provenance

FoamPilot was independently extracted and developed after studying
[Foam-Agent](https://github.com/csml-rpi/Foam-Agent), which is distributed
under the MIT License. The upstream copyright notice and license text are
retained in this repository's `LICENSE`.

FoamPilot has no runtime dependency on Foam-Agent and is not presented as an
official continuation of that project. The new repository has an independent
Git history.

FoamPilot is not affiliated with or endorsed by the OpenFOAM Foundation.
OpenFOAM is used as an external numerical runtime. Official OpenFOAM tutorial
case files are not distributed in this repository.

The official-six qualification includes compact derived numeric references
and evaluator rules for reproducible Agent assessment. Those assets remain
evaluator-owned and are not exposed to the case-authoring model.
